## ✨ Key Features

- 🔍 **Smart Matching:** Algorithm based on user interests, preferences, and location.
- 💬 **Real-Time Messaging:** Instant and secure communication between matched users.
- 🎨 **Modern & Clean UI:** Highly polished design featuring Glassmorphism and Bento Grid layout concepts.
- 🔒 **Security & Privacy:** Secure authentication, profile verification, and user reporting mechanisms.
- 🔔 **Push Notifications:** Instant alerts for new matches and incoming messages.
